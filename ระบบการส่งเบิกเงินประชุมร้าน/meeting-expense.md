# ระบบเบิกเงินประชุมร้าน

ไฟล์: `meeting-expense.html` — เว็บแอปไฟล์เดียว ใช้ฐานข้อมูลกลางของ Artifact

## ใช้ทำอะไร

ให้สาขาส่งบิลเบิกค่าประชุมร้านรายเดือนผ่านมือถือ ฝ่ายบัญชีคุมวงเงิน เปิด–ปิดรอบ ตรวจอนุมัติ และดูแลว่าใครเป็นคนรับเงินของแต่ละสาขา

## การเข้าใช้งาน

ใช้รหัสอย่างเดียว ไม่มี username

- **เปิดครั้งแรก** ระบบขอให้ตั้ง "รหัสผู้ดูแล" → รหัสนี้คือรหัสฝ่ายบัญชี
- **รหัสสาขา** ฝ่ายบัญชีสร้างให้ในแท็บ "สาขา & วงเงิน" แล้วส่งรหัสให้ผู้จัดการสาขา
- ระบบจำรหัสไว้ในเครื่อง ปุ่ม "ออก" ที่มุมขวาบนใช้ล็อกเอาต์

## ฝั่งสาขา

**รอบปัจจุบัน** — หัวจอแสดง วงเงิน / ส่งเบิกแล้ว / คงเหลือ พร้อมแถบวัด
ปุ่ม "ส่งบิลเบิกเงิน" (กดไม่ได้ถ้ารอบปิด) → กรอกจำนวนเงิน วันที่ประชุม ผู้รับเงิน รายละเอียด และ**ต้องแนบรูปบิลอย่างน้อย 1 รูป**
บิลที่ส่งจะแสดงเป็นสลิป สถานะ รอตรวจ / อนุมัติแล้ว / ไม่อนุมัติ พร้อมหมายเหตุจากบัญชี

**ประวัติย้อนหลัง** — แยกตามรอบ พร้อมยอดที่อนุมัติของแต่ละรอบ

**ผู้รับเงิน** — ดูคนรับเงินปัจจุบัน และกด "แจ้งเปลี่ยนผู้รับเงิน" ส่งคำขอไปให้บัญชีอนุมัติ (ขอค้างได้ครั้งละ 1 คำขอ)

## ฝั่งฝ่ายบัญชี

| แท็บ | ทำอะไรได้ |
|---|---|
| บิลเบิก | เลือกดูตามรอบหรือทุกรอบ, สรุปยอดรอตรวจ/อนุมัติ, กดอนุมัติ–ไม่อนุมัติพร้อมหมายเหตุ |
| รอบเบิก | เปิดรอบใหม่ (เลือกเดือน, วงเงินต่อสาขา, วันสุดท้ายที่ส่งบิล), ปิด/เปิดรับบิลอีกครั้ง |
| สาขา & วงเงิน | ตั้งวงเงินเริ่มต้นทุกสาขา, เพิ่ม/แก้/ลบสาขา, ตั้งวงเงินเฉพาะสาขา |
| ผู้รับเงิน | อนุมัติ/ปฏิเสธคำขอเปลี่ยนผู้รับเงิน หรือตั้งชื่อผู้รับเงินเองได้เลย |

## ลำดับความสำคัญของวงเงิน

วงเงินเฉพาะรอบ → วงเงินเฉพาะสาขา → วงเงินเริ่มต้น
ใส่ 0 ที่ช่องไหน = ให้ตกไปใช้ค่าถัดไป

## กติกาที่ระบบบังคับให้

- ส่งบิลได้เฉพาะตอนรอบเปิด
- ยอดรวมที่ส่ง (ไม่นับใบที่ไม่อนุมัติ) เกินวงเงินไม่ได้
- ต้องแนบรูปบิล
- รหัสสาขาซ้ำกัน หรือซ้ำกับรหัสฝ่ายบัญชีไม่ได้
- เปิดรอบเดือนซ้ำไม่ได้

## โครงข้อมูล

| ที่เก็บ | เนื้อหา |
|---|---|
| `meta/config` | adminCode, branches[{code,name,limit}], defaultLimit |
| `rounds/<YYYY-MM>` | open, limitDefault, dueDate, limits{} |
| `claims/<id>` | roundId, branchCode, branchName, amount, meetDate, payee, note, photoIds[], status, reviewNote |
| `payees/<branchCode>` | name, note, updatedAt |
| `payeeReq/<id>` | branchCode, newName, bank, reason, status |
| `photos/<id>` | รูปบิล base64 (ย่อ ≤1100px คุมไม่เกิน ~170KB ต่อรูป) |

## หมายเหตุ

- ทุกคนที่มีรหัสฝ่ายบัญชีทำได้ทุกอย่าง ระบบไม่แยกสิทธิ์ย่อย ควรจำกัดคนที่รู้รหัส
- ลบรอบไม่ได้ ใช้วิธีปิดรอบแทน
- โหมดมืดตามการตั้งค่าเครื่อง
- ฐานข้อมูลรวมทุกเอกสารได้สูงสุด 5,000 รายการ (รวมรูปบิล) ถ้าเก็บหลายปีควรวางแผนล้างรูปเก่า
